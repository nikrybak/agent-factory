Этот скилл — часть инфраструктуры **Multi-AI Software Factory** (stack-agnostic база: `look-at-me`,
`vc_enterprise_it_infra`), а не универсальный справочник. В глобальном хранилище он лежит ради
доступности и применим ТОЛЬКО в проектах этой инфраструктуры.

Перед любым действием проверить в корне проекта оба маркера:

1. `AGENTS.md` существует и содержит `Factory City`;
2. существует `cli/bin/infra.js`.

**Оба есть** — выполнять как описано ниже.

**Хотя бы одного нет** — скилл неприменим. НЕ выполнять процедуру, НЕ требовать доказательств от
под-гейтов, НЕ блокировать commit / push / release. Одной строкой сообщить, что проект не на
инфраструктуре Software Factory, и продолжить обычным порядком.

# factory-continuous-learning-flow

Локальная **пер-сессионная** обёртка над глобальным скиллом `continuous-learning-v2`
(механизм «инстинктов» — извлечение durable-уроков из выполнения). Делает обучение
базы воспроизводимым: то, что усвоено во время выполнения, повышается прямо до
долговременной памяти роли. Отдельного сессионного журнала нет (ADR-0021 п.11),
сырьё берётся из самой сессии.

Связь со смежными артефактами:

- Факты сессии — **сырьё**: `git diff --stat` и `git log` сессии, вердикты гейтов,
  ошибки и ловушки, на которые наступили, решения, принятые по ходу.
- `continuous-learning-v2` (глобальный) — **движок различения** durable vs разовое;
  этот скилл вызывает его явно на каждом кандидате из сессии.
- `factory-consolidate-memory` (канон) — **периодический** догоняющий проход: дедуп и
  промоушен устойчивых паттернов выше, в `skills/`/`rules/`. Здесь работаем по
  одной сессии; накопленную консолидацию оставляем ему.

## When to Use

- В рабочем пути из `AGENTS.md` — между шагом 11 `/factory-docs-sync` и шагом 13
  `/factory-release-checkpoint` (то есть на стыке «доки обновлены» → «фиксируем чекпоинт»).
- Когда в сессии встретилась ошибка, ловушка или решение, которое повторится
  (правило, инвариант, грабли), и его ещё нет в памяти роли.
- После заметного прогресса, когда в `.claude/agent-memory/*/MEMORY.md` накопились
  разрозненные наблюдения, которые пора обобщить в durable-паттерн.
- НЕ запускать для тривиальных правок без архитектурных/процессных уроков — память
  ролей не должна превращаться в шум.
- Для периодической дедупликации и продвижения устойчивых паттернов выше (в
  `skills/`/`rules/`) — НЕ здесь, а в `factory-consolidate-memory`. Этот скилл — пер-сессионный.

## How It Works

1. Собрать кандидатов из текущей сессии: `git diff --stat` / `git log` сессии,
   вердикты гейтов, ошибки и ловушки, принятые решения.
2. Прочитать `.claude/agent-memory/*/MEMORY.md` по всем ролям; если каталога
   `.claude/agent-memory/<role>/` ещё нет — создать его и `MEMORY.md` для роли,
   к которой относится паттерн.
3. **Явно вызвать глобальный `continuous-learning-v2`** (инстинкты) на каждом
   кандидате: отличить durable-паттерн (правило, инвариант, грабли, которые
   повторятся) от разового факта. Разовые факты не промоутим.
4. Записать durable-паттерн в `MEMORY.md` релевантной роли (например, security →
   `security-engineer`, релизы/секреты в гите → `devops-release-engineer`,
   парсинг/инструменты → `documentation-engineer`/соответствующий инженер).
5. Если паттерн общий для базы (не только для одной роли), добавить одну строку и в
   `docs/operations/MEMORY.md` («Текущее состояние» / «Активные риски»); это снимок
   «как сейчас», а не журнал.
6. Держать формулировки короткими и проверяемыми; дубли с уже имеющимся в `MEMORY.md`
   не плодить — обновлять существующий пункт.

## Examples

- После `/factory-docs-sync` в сессии были правки генератора frontmatter. Скилл
  извлекает паттерн «нормализуй CRLF→LF перед regex по frontmatter» и промоутит его
  в `.claude/agent-memory/documentation-engineer/MEMORY.md`.
- Зафиксировано, что `.mcp.json` чуть не попал в коммит. Скилл повышает правило
  «секреты гитигнорятся на корне канона; локальное — только в `*.local.*`» в
  `.claude/agent-memory/security-engineer/MEMORY.md` и
  `.claude/agent-memory/devops-release-engineer/MEMORY.md`.
- Перед `/factory-release-checkpoint` скилл проходит все `MEMORY.md`, схлопывает три похожих
  наблюдения про флаки e2e в один durable-пункт в
  `.claude/agent-memory/e2e-test-engineer/MEMORY.md`.

## Required final report

- Status: PASS / FAIL / PASS WITH RISKS
- Roles used
- Skills/plugins/MCP used (включая `continuous-learning-v2`)
- Files changed (затронутые `agent-memory/*/MEMORY.md`, при общем паттерне `docs/operations/MEMORY.md`)
- Tests/checks run
- Docs updated
- Open risks
