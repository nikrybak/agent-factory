# factory-browser-e2e-gate

Run Playwright/browser QA for UI changes.

## Procedure


1. Use global `browser-qa`, `e2e-testing`, `windows-desktop-e2e` where relevant.
2. Use Playwright plugin/CLI for repeatable tests.
3. Use Chrome DevTools MCP for live debugging/performance/network when failure is unclear.
4. Store scenarios in `docs/testing/E2E_POLICY.md` and tests in project test folder.


## Required final report

- Status: PASS / FAIL / PASS WITH RISKS
- Roles used
- Skills/plugins/MCP used
- Files changed
- Tests/checks run
- Docs updated
- Open risks
