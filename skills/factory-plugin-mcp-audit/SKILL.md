# factory-plugin-mcp-audit

Audit installed Claude plugins and MCP servers; use plugin details and mcp list.

## Procedure


1. Run `claude plugin list`.
2. Run `claude plugin details <plugin>` for installed plugins.
3. Run `claude mcp list` and `/mcp`.
4. Check duplicate MCP servers and broken plugin configs.
5. Update `docs/plugins/PLUGIN_USAGE.md` and `docs/plugins/MCP_SERVERS.md`.


## Required final report

- Status: PASS / FAIL / PASS WITH RISKS
- Roles used
- Skills/plugins/MCP used
- Files changed
- Tests/checks run
- Docs updated
- Open risks
