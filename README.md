# Agent Factory - витрина

Срез моей мульти-ИИ фабрики разработки: один контракт для Claude Code, Codex, Gemini и Cursor, роли агентов, хуки-гейты, CLI с очередью сборок и выбором затронутых тестов

Полный монорепозиторий приватный - в нём игры, сервисы и ключи

Здесь только инфраструктура работы с агентами, без продуктового кода и секретов

## Что сделано лично мной

- `AGENTS.md` - единый контракт для всех агентов: стандарты, безопасность, процесс за блокирующими гейтами, формат отчёта
- `cli/lib/generators/` - из одного канона собираются конфиги под Claude, Codex, Cursor и Gemini, `infra sync --check` ловит дрейф в CI
- `.claude/agents/` и `.codex/agents/` - 24 роли (оркестратор, архитектор, backend, QA, security, performance и другие)
- `skills/factory-*` - 30 собственных скиллов: intake, план, реализация, тест-гейт, security-гейт, release checkpoint, быстрая проверка
- `.claude/hooks/` - хуки на каждый вызов инструмента: запрет чтения секретов, гейт качества на Stop, аудит после инструмента, один процесс-диспетчер вместо пачки скриптов
- `cli/lib/machine-queue.js` - общая очередь тяжёлых задач на машину: параллельные агенты не душат друг друга сборками
- `cli/lib/impacted.js`, `testcache.js`, `node-test-memo.js` - агент гоняет только тесты, которые достаёт его правка, с кэшем по содержимому
- `cli/lib/factory/` - Factory City: план, запуск, ledger, трассируемость, SBOM, аттестации, eval и `certify`
- `docs/adr/` - 29 решений, каждое из живой проблемы (очередь сборок, локальные раннеры CI, защита GitHub Actions, "дефект закрывается уроком")

## Цифры

- проверка правки только по затронутым тестам - 67 с вместо 9-15 минут
- полная проверка 19 модулей - 6,5 минуты
- 8 параллельных агентов на 8 ядрах держали очередь часами - лимит 4 агента плюс координатор вернул пропускную способность

## Запуск

```bash
node cli/bin/infra.js doctor
node cli/bin/infra.js sync --check
node --test "cli/test/*.test.js"
python -m pytest tests
```

6 тестов помечены skip: им нужен полный приватный монорепозиторий (реестр дочерних проектов и канон скиллов)

`machine-queue.test.js` меряет реальную очередь машины и на загруженном хосте может упереться в таймаут
