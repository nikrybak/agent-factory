# Definition of Done

A task is done only when:

- [ ] Acceptance criteria are satisfied.
- [ ] Architecture impact reviewed.
- [ ] Tests exist for changed/new modules.
- [ ] Quality gate PASS.
- [ ] Security reviewed where relevant.
- [ ] Docs/app-architecture updated.
- [ ] ADR updated if required.
- [ ] Memory/checkpoint/tasks updated.
- [ ] User-visible summary provided.
